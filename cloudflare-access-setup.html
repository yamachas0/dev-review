セキュリティ設定・作業手順

Cloudflare Access 設定手順書
— sim.mud-ai.com に「鍵」をかける

対象URL: sim.mud-ai.com
所要時間の目安: 5〜10分
作業する場所: Cloudflareのダッシュボード（設定画面）のみ

今の状態: 「P0止血（緊急の穴ふさぎ）」という応急処置により、公開URL（sim.mud-ai.com）は今、「画面は開くが、計算は動かない」安全な状態になっています。他社の検討履歴が誰でも見えてしまっていた穴はすでに塞ぎました。この手順書では、Cloudflare Access（アクセスできる人を、指定したメールアドレスの人だけに絞る仕組み）を設定して、「指定した人だけが入れる鍵」をかけます。

先に知っておくこと

この設定だけでは、外から計算はまだ動きません

今回の手順は「誰が画面を見られるか」を絞るだけです。「計算そのものを外から動かせるようにする」には、サーバー側のスイッチをもう一つ入れる作業（統括側で対応）が別途必要です。それはこの手順とセットで別途仕上げます。この手順を終えた直後に「計算が動かない」と思っても異常ではありません。

手順

1
ダッシュボードにログイン

ブラウザで https://one.dash.cloudflare.com/ を開き、Cloudflare（サイトの表示やアクセス制御を担うサービス）のダッシュボード（設定画面）にログインします。

2
Access のメニューを開く

左側のメニューから Access → Applications を選びます。

3
アプリケーションを追加

Add an application ボタンを押し、種類は Self-hosted（自社で動かしているサイト、の意味）を選びます。

4
基本情報を入力
  • Application name: shoseido-sim（名前はわかりやすければ何でもOKです）
  • Session Duration（一度認証したら何時間有効か）: 24 hours
  • Application domain（対象のURL）: sim.mud-ai.com
5
次へ進む

Next ボタンを押します。

6
ポリシー（誰を許可するかのルール）を作成 — 最重要ステップ
  • Policy name: allow-list
  • Action: Allow
  • Configure rules の中の Include で、選択項目から Emails を選びます。
  • そこに、許可するメールアドレスを1件ずつ追加します（山川さん本人のメールアドレス ＋ JRE側の担当者のメールアドレス）。
⚠ 最重要の注意

「Login method = One-time PIN」だけの設定に絶対にしないでください

ログイン方法（Login method）を One-time PIN（毎回メールに届く一時的な暗証番号）にするだけで満足してしまうと、有効なメールアドレスを持っている人なら誰でも入れてしまいます（Cloudflare公式も注意喚起している落とし穴です）。

必ず、上の手順6の Emails（メールアドレスを個別に指定する項目）で、許可したい人のアドレスをひとつずつ登録してください。これが「指定した人だけが入れる鍵」の実体です。

7
保存して完了

Next → Add application を押して保存します。

8
これで完了

これ以降、sim.mud-ai.com にアクセスすると、メールアドレスの入力とワンタイムPIN（毎回メールに届く一時的な暗証番号）の入力が求められる画面が出るようになります。登録したメールアドレス以外の人はここで弾かれます。

設定後の確認

ブラウザの「シークレットウィンドウ」（ログイン状態を持たない、新規のプライベートな閲覧画面）で https://sim.mud-ai.com を開く
メールアドレスの入力欄が表示され、ワンタイムPINの入力を求められることを確認する
登録したメールアドレスで実際にPINを受け取り、入力して画面に入れることを確認する

人を追加・削除したい時は、同じポリシー（allow-list）の Emails のリストを編集するだけです。個人単位で発行・失効できます。費用は50ユーザーまで無料です。

うまくいかない時（トラブルシュート）

  • Access の認証画面が出ずに、いきなり中身が見えてしまう、または全く違うエラーになる場合→DNS（ドメイン名とサーバーの住所を結びつける設定）が sim.mud-ai.com を正しく指しているか確認してください。
  • サイト自体が開かない（真っ白・エラー）場合→Tunnel（このPCとインターネットを安全につなぐ経路）が起動しているかどうかの確認が必要です。これは統括側で確認します。
  • 迷ったら、この画面のスクリーンショットを撮ってDiscordに送ってもらえれば、そこから先を一緒に確認します。

この手順書は sim.mud-ai.com のアクセス制限（Cloudflare Access）設定用です。設定後は「サーバー側のスイッチ」対応と合わせてセットで仕上げます。
